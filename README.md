# نبض ورزش

نتایج زنده، برنامه بازی‌های امروز به وقت تهران، رویدادهای هر بازی (گل، کارت، تعویض، پنالتی) و لینک «تماشا» به پخش رسمی آنتن.

- صفحه اصلی: `index.html` (فیلترهای همه، زنده، ایران، فوتبال، والیبال، بسکتبال، مهم‌ها)
- صفحه بازی: `match.html?id=football-123`
- داده‌ها: سایت ابتدا مستقیم از منبع زنده می‌خواند؛ اگر نشد، از نسخه‌ای که هر ۵ دقیقه با `scripts/build_data.py` در `data/` ساخته می‌شود.
- انتشار: GitHub Pages با workflow `.github/workflows/pages.yml`.

این سایت هیچ پخش ویدیویی ندارد و فقط به صفحه پخش رسمی لینک می‌دهد.
